Genotype error probability
==========================

Format
~~~~~~

There is one line per locus with one value,
namely the *genotype error probability*.

Example with four loci:

::

  0.050000
  0.050000
  0.000100
  0.000100

Output details
~~~~~~~~~~~~~~

The file is saved as ``.geno_error_prob.txt``.
