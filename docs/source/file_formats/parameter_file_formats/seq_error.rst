Sequence error probability
==========================

Format
~~~~~~

There is one line per locus with one value,
namely the *sequence error probability*.

Example with four loci:

::

  0.000137
  0.000100
  0.000362
  0.000100


Output details
~~~~~~~~~~~~~~

The file is saved as ``.seq_error_prob.txt``.
